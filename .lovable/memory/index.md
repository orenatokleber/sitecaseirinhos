# Project Memory

## Core
Brand colors: Turquoise #40e0d0 (primary), Chocolate #936037, Gold #ca9e67 (accent), Cream #f7f5e2 (bg).
Fonts: Playfair Display (headings), Nunito (body), Dancing Script (accents).
Tech Stack: Supabase (DB, Auth, Storage) + Edge Functions on Lovable Cloud.
Admin restricted to `caseirinhosaconfeitaria@gmail.com` at `/painel-admin`.
Mobile-first responsive admin and blog editor.
Media constraints: 16:9 for banners/hero, 1:1 for product/gallery photos.
Smooth page transitions (fade, slide-up) with auto-scroll management.
